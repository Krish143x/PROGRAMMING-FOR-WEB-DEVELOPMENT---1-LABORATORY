# Web Development Lab — P1 to P13

This folder contains:
- P1–P4: Git and GitHub terminal activities (instructions are in the lab record DOCX).
- P5–P13: Standalone HTML/CSS practical programs. Open each folder's `index.html` in a browser.

## Programs
- P5: Semantic Bio Page
- P6: Full Portfolio Page Structure in Semantic HTML
- P7: Design Tokens and Typography System in CSS
- P8: Sticky Navbar and Card Overlay Using CSS Positioning
- P9: Responsive Navbar and Card Grid Using Flexbox
- P10: Portfolio Header and Footer with Advanced Flexbox
- P11: Newspaper-Style Three-Column Layout with CSS Grid
- P12: Portfolio Projects Grid with Advanced CSS Grid
- P13: Choosing Between Flexbox and Grid for a Shared Layout

## How to run
1. Open the folder for a program, for example `P9`.
2. Open `index.html` in Chrome, Safari, Firefox or another browser.
3. Resize the browser window to test responsive layouts.

The personal portfolio examples use the name Sai Surve and the placeholder email sai.surve@example.com. The campus news example is affiliated with Bosscoder School of Technology.
