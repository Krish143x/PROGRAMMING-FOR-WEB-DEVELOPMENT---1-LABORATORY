Flexbox and CSS Grid

Flexbox is best for arranging items in one direction, either a row or a column. CSS Grid is best for arranging items in rows and columns together.

When to Use

Flexbox: navigation bars, button groups and aligned items.

Grid: page layouts, galleries and rows-and-columns structures.
